# サギカモ

**「これって詐欺かも?」と思ったら、撮って送るだけ。**

不審な電話・メール・SMS・SNS・ハガキの内容を、生成AIと東京都のオープンデータで見立てる詐欺被害防止サービスです。
都知事杯オープンデータ・ハッカソン2026 応募作品。

🔗 **デモ**: https://sagikamo.sagikanchi.workers.dev

## 特徴

- **4つの入口**: 電話チェック（ボタンをえらぶだけ・文字入力不要）／カメラ撮影（ハガキ・別端末の画面）／文面貼り付け／音声入力。リテラシーを問わず使える設計
- **判定 × 実データ**: AIの見立て（手口の型・危険度・根拠）に、警視庁オープンデータによる「あなたの街の認知件数」を必ず併記
- **断定しない**: 「詐欺です/ではありません」とは言わない。3段階の見立て＋根拠＋次にすべき行動（110/#9110/188）を提示
- **リスクマップ**: 62区市町村を全年代/高齢者別のリスク指数で色分け。区市町村内の町丁トップ5も表示
- **まもるカード**: 判定結果・手口図鑑から家族向けの注意喚起画像を生成し、LINE等で共有
- **プライバシー**: 貼り付けた文面・画像はその場で判定して破棄。サーバー・ログに保存しない

## 使用データ（東京都オープンデータ）

| データ | 提供元 | 用途 |
|---|---|---|
| 区市町村の町丁別、罪種別及び手口別認知件数（月累計） | 警視庁 | 地域の詐欺認知件数・町丁ランキング |
| 住民基本台帳による東京都の世帯と人口（町丁別・年齢別） | 東京都総務局 | リスク指数の分母（全年代・65歳以上人口） |
| 高齢者等の異変に気付いた際の区市町村連絡先一覧 | 東京都福祉局 | 区市町村別の相談窓口 |
| 手口分類（知識ベース） | 警察庁・警視庁 公表資料 | 判定・手口図鑑 |

地図境界: 国土交通省 国土数値情報（行政区域データ）を加工して使用。

## 技術構成

- フロント: React (Vite) + MapLibre GL JS
- バック: Cloudflare Workers（静的配信＋判定プロキシAPI）
- 判定: LLM（構造化出力・enumで断定表現を構造的に排除）
- データ: 月次バッチで取得・検算した静的JSON（リクエスト時に外部APIを直叩きしない）

## 開発

```bash
npm install
# .dev.vars に ANTHROPIC_API_KEY=... を設定（コミット禁止）
npm run dev             # 開発サーバー（判定API内蔵）
npm run fetch-opendata  # オープンデータ取得
npm run build-stats     # 統計JSON生成
npm run verify-stats    # 独立検算（27項目）
npm run eval            # 判定精度評価（テストセット）
npm run deploy          # ビルド＆Cloudflareへデプロイ
```

詳細は `CLAUDE.md`（開発ルール）、`docs/spec.md`（仕様）、`docs/data.md`（データ調査）を参照。

## 注意事項

- 判定はAIによる「見立て」であり、詐欺かどうかを断定するものではありません
- 統計値はすべて出典付きの公開データに基づきます（画面に出典・取得日を表示）
- 相談窓口: 110（緊急）／#9110（警察相談専用電話）／188（消費者ホットライン）
